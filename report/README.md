# Final project report

[PDF](Duck2_Project_Report.pdf) · [LaTeX source](Duck2_Project_Report.tex)

Authors: **Tair Kezdekbayev, Alvaro Mendez Li and Tan Kayra Erol**.
All three names appear in the title and PDF metadata, without an email address.
The report explains the architecture, lane/junction control, directed A* map,
live chatbot, operation and remaining physical limitations.

Compile from this folder using a TeX installation with the declared packages:

```text
tectonic Duck2_Project_Report.tex
```

Alternatively run `pdflatex Duck2_Project_Report.tex` twice. Keep intermediate
files outside the repository. The PDF and editable source are both deliverables.
