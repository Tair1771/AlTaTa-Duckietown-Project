# Project report

[PDF](Duck2_Project_Report.pdf) · [LaTeX source](Duck2_Project_Report.tex)

Updated 2026-09-10 in the original two-column academic format. The report
authors are **Tair Kezdekbayev, Alvaro Mendez Li and Tan Kayra Erol**; the title
and PDF metadata include all three names, without an email address. The report
describes the implemented live chatbot, its commands, rule development,
directed planning, ROS architecture and recorded evidence. Its physical
results distinguish accepted component trials from the latest incomplete run.

Compile using a TeX installation with the packages declared in the source:

```text
tectonic Duck2_Project_Report.tex
```

Alternatively run `pdflatex Duck2_Project_Report.tex` twice from this folder.
Tectonic resolves references on its own. Compilation needs neither the robot
nor Docker. Keep temporary `.aux`, `.log` and rendered review images outside
the repository. The PDF and source are deliverables; the legal notice in the
repository root remains applicable to the software.
